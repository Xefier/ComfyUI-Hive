# ComfyUI-Hive

A HiveOS custom miner that runs [ComfyUI](https://github.com/comfyanonymous/ComfyUI) generation workloads on a rig's GPU.
The workflow is picked in the flight sheet; Wan2.2 (text-to-video / image-to-video) is the first one supported.

Sister project of [Ollama-Hive](https://github.com/Xefier/Ollama-Hive).

Status: just started, nothing built yet.
